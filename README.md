# 📈 A股信号分析系统

个人A股信号判断系统，基于5正交因子模型，为新手股民提供系统化的买卖参考建议。

## ✨ 核心功能

### 评分模型
- **5正交因子模型**：趋势动量 / 波动率 / 量价关系 / 相对强度 / 基本面，避免多指标共线性问题
- **Z-Score + 百分位排名**：用统计标准化替代硬编码阈值，自适应不同市场环境
- **动态权重**：根据大盘环境（牛市/震荡/熊市）自动调整各因子权重
- **趋势动量一票否决**：趋势得分 < 25 直接判否，避免逆势操作

### 风险管理
- ATR 动态止损（价格 - 2×ATR）
- 1/4 Kelly 仓位管理
- 盈亏比（R/R）计算
- 风险等级评估（低/中/高）

### 回测引擎
- Walk-forward 滚动回测
- 胜率、平均收益、最大回撤、夏普比率、盈亏比

### 可视化界面
- ECharts 专业K线图（日/周/月 + MA + BOLL 叠加）
- 成交量、MACD、RSI+ADX 副图
- 因子雷达图 + 评分进度条
- 信号趋势折线图（7日评分历史）
- 场景推演（乐观/中性/悲观）

### 易懂易用
- **大白话解读**：自动生成三段式建议（情况/操作/计划）
- **名词百科**：25+ 技术术语悬浮提示
- **自选股管理**：浮动抽屉式，不占内容空间
- **每日扫描**：一键扫描全部自选股信号
- **组合仪表盘**：行业集中度检查、组合风险评估

## 🛠 技术栈

| 层 | 技术 |
|---|---|

## 📊 评分因子说明

| 因子 | 权重(基准) | 核心指标 | 含义 |
|---|---|---|---|
| 趋势动量 | 25% | MACD + ADX | 趋势方向与强度，<25一票否决 |
| 波动率 | 15% | BOLL + ATR | 价格波动是否处于健康区间 |
| 量价关系 | 15% | OBV + MFI | 量价是否配合，资金流向 |
| 相对强度 | 15% | RSI 百分位 | 相对大盘的表现强弱 |
| 基本面 | 30% | PE + PB + ROE 百分位 | 估值是否合理，盈利能力 |

> 权重会根据大盘环境（牛市/震荡/熊市）动态调整。
