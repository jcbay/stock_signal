# A股信号分析系统

个人 A 股信号判断系统。基于 5 正交因子量化模型，为新手股民提供系统化的买卖参考，并内置持仓管理、交易日志、智能预警等闭环功能。

> 免责：本系统仅供个人学习与技术研究，所有评分均为模型输出，不构成任何投资建议。股市有风险，投资需谨慎。

## 1. 功能特性

### 1.1 信号评分引擎
- **5 正交因子模型**：趋势动量 / 波动率 / 量价关系 / 相对强度 / 基本面，避免多指标共线性
- **Z-Score + 百分位排名**：用统计标准化替代硬编码阈值，自适应不同市场环境
- **动态权重**：根据大盘环境（牛市 / 震荡 / 熊市）自动调整因子权重
- **趋势动量一票否决**：趋势得分 < 25 直接判否，避免逆势操作
- **ETF 专属路径**：对 ETF 采用流动性因子替代估值因子，单独建模

### 1.2 风险管理与回测
- ATR 动态止损（价格 - 2×ATR）、1/4 Kelly 仓位管理、盈亏比（R/R）、风险等级评估
- Walk-forward 滚动回测：胜率、平均收益、最大回撤、夏普比率、盈亏比

### 1.3 可视化与易懂
- ECharts 专业 K 线图（日 / 周 / 月 + MA + BOLL 叠加），成交量、MACD、RSI+ADX 副图
- 因子雷达图 + 评分进度条、信号趋势折线（评分历史）、场景推演（乐观 / 中性 / 悲观）
- **大白话解读**：自动生成三段式建议（情况 / 操作 / 计划）
- **名词百科**：25+ 技术术语悬浮提示

### 1.4 持仓管理（v4）
- **单向数据流**：持仓**只能由交易记录创建和更新**，杜绝账实不一致
- 实时行情批量获取 + 盈亏计算（市值 / 成本 / 收益率 / 今日盈亏）
- 智能建议：止损 / 止盈 / 操作参考 / 组合建议
  - **Recovery 整合建议（v4.1）**：深套（亏损 ≥15%）+ 信号转好（看多 ≥60）时，给出补仓摊薄、反弹减仓、止损换股三选一，而非一刀切止损

### 1.5 交易日志与信号命中率（v4）
- 记录每笔买卖并自动保存当时信号评分
- 回溯推荐股票后续表现，统计信号买入 / 卖出命中率

### 1.6 智能预警中心（v4）
- **8 类预警**：价格上穿 / 价格下穿 / 信号看多（评分突破）/ 信号看空（评分跌破）/ 止损（持仓亏损%）/ 止盈（持仓盈利%）/ 当日大跌 / 当日大涨
- 手动「立即检查预警」即时判定；命中后页面标红 + 红色横幅 + 首页卡片同步显示
- 规则可新建 / 删除 / 重置
- 说明：当前为手动检查模式，不会自动轮询或推送，需要时点一下「立即检查预警」

### 1.7 自选股与每日扫描
- 浮动抽屉式自选股管理，不占用内容区
- 每日一键扫描全部自选股信号

| 层 | 技术 |

## 3. 项目结构

```
stock_signal/
├── app.py              # Flask 主应用：路由、API、页面渲染
├── data_fetcher.py     # 数据获取（新浪/腾讯双源 + SQLite 缓存，curl 直连绕过代理）
├── indicators.py       # 技术指标计算
├── scorer.py           # 5因子评分 / 回测 / 风险管理 / 大白话解读 / 场景推演
├── db.py               # SQLite 数据层（建表、读写、日期格式统一）
├── portfolio.py        # 持仓管理 + 智能建议（含 recovery 逻辑）
├── trade_journal.py    # 交易日志 + 信号命中率 + 持仓同步（单向数据流入口）
├── alert_checker.py    # 智能预警：8类规则检查与汇总
├── static/             # 前端静态资源（JS / CSS）
├── templates/
│   ├── index.html      # 分析主页（K线/因子/回测/场景/信号趋势）
│   ├── portfolio.html  # 持仓管理页
│   ├── journal.html    # 交易日志 + 命中率页
│   └── alerts.html     # 智能预警中心页
├── start.sh            # 启动脚本（自动创建 venv 并安装依赖，后台运行）
├── stop.sh             # 停止脚本
├── render.yaml         # Render 云端部署配置
├── requirements.txt    # Python 依赖
├── .gitignore
└── README.md
```

## 5. 本地部署运行

### 方式一：使用启动脚本（推荐）

```bash
git clone https://github.com/jcbay/stock_signal.git
cd stock_signal
chmod +x start.sh        # 首次需赋予执行权限
./start.sh
```

首次运行会自动完成：创建 Python 虚拟环境（`venv/`）→ 安装依赖 → 后台启动服务。
启动成功后访问 **http://localhost:8080**。

- 查看日志：`tail -f server.log`
- 停止服务：`./stop.sh`

### 方式二：手动创建虚拟环境

```bash
git clone https://github.com/jcbay/stock_signal.git
cd stock_signal
python3 -m venv venv
venv/bin/pip install -r requirements.txt
venv/bin/python app.py
```

访问 **http://localhost:8080**（默认端口 8080）。

### 自定义端口

服务读取环境变量 `PORT`（默认 8080）：

```bash
PORT=9000 ./start.sh
# 或手动方式
PORT=9000 venv/bin/python app.py
```

## 6. 云端部署（Render，免费）

仓库已内置 `render.yaml`，可直接在 [Render](https://render.com) 一键部署：

1. 在 Render 新建 **Web Service**，关联本 GitHub 仓库（`jcbay/stock_signal`）。
2. Render 会自动读取 `render.yaml`：
   - 构建命令：`pip install -r requirements.txt`
   - 启动命令：`gunicorn app:app --workers 2 --timeout 120`
   - 环境变量：`PYTHON_VERSION=3.11.6`、`FLASK_DEBUG=0`
3. Render 提供 `PORT` 环境变量，服务监听该端口，部署完成后给出 `https://` 域名。
4. 免费实例在休眠后首次访问会有冷启动延迟，属正常现象。

> 注意：Render 默认实例位于境外，可能无法访问新浪 / 腾讯数据源（详见第 8 节），导致行情为空。若部署在境外，请自行配置可访问国内接口的网络环境。

## 7. 首次运行与数据

- 首次启动会**自动创建 SQLite 数据库与所有数据表**（默认 `stock_data.db`），无需手动建库。
- 系统**不包含任何预置持仓、交易或预警数据**。请在使用时通过页面自行录入：
  1. 在分析页输入股票代码查看信号；
  2. 在「交易日志」记录买入 / 卖出（系统据此自动创建 / 更新持仓）；
  3. 在「持仓」查看盈亏与智能建议；
  4. 在「预警中心」设置关注条件，需要时点「立即检查预警」；
  5. 用「自选股」抽屉添加关注标的，可用「每日扫描」批量查看。

## 8. 数据源与网络说明（重要）

- 历史 K 线来自**新浪财经**，实时行情与基本面来自**腾讯财经**，均为公开 HTTP 接口。
- 系统通过本地 `curl` **直连**数据源，并已规避系统代理干扰；若你的环境设置了全局代理，数据获取逻辑会自动绕过。
- **网络环境要求**：数据源服务器主要面向中国大陆网络。若部署在境外或受限网络，接口可能超时 / 返回空，表现为行情、评分加载失败。建议将服务运行在可正常访问上述接口的网络中。
- 行情接口为非官方公开接口，可能随对方策略调整而变动；如长期获取失败，需检查 `data_fetcher.py` 中的接口地址。

## 10. 常见问题排查

| 现象 | 排查方向 |
|---|---|
| 页面打不开 / 502 | 确认服务已启动（`./start.sh` 成功），端口是否为 8080；查看 `server.log` |
| 行情 / 评分为空 | 检查网络能否访问新浪 / 腾讯；代理或境外环境见第 8 节 |
| 依赖安装失败 | 确认 Python 版本 ≥ 3.10；尝试 `venv/bin/pip install -r requirements.txt` |
| 端口被占用 | 用 `PORT=9000 ./start.sh` 更换端口 |
| 修改代码不生效 | 重启服务：`./stop.sh` 后 `./start.sh` |
